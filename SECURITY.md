# Reporting a security problem

If you find a way to see or change data you shouldn't, or any other security issue in KNOT, please email **pritam14chavhan@gmail.com** with the subject "KNOT security" instead of opening a public issue.

Please include what you did, what you expected and what happened. You'll get a reply within a few days, and a fix as soon as possible.

Please don't access other students' data beyond what's needed to show the problem.

How KNOT protects data is described in [docs/SECURITY.md](docs/SECURITY.md).
